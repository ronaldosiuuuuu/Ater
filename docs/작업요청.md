# 작업 요청 양식

클로드 코드에도, claude.ai의 Claude에게도 똑같이 쓴다. 파일 이름이나 코드는 몰라도 된다. **게임을 하는 사람 눈으로** 적는다.

## 복사해서 쓰는 칸

```
[하고 싶은 것]
게임에서 무엇이 어떻게 달라지면 좋겠는지.
버그라면: 언제 · 무엇을 했을 때 · 무슨 일이 생기는지 (예: 태그매치에서 교대하자마자 쓰러지면 화면이 멈춘다)

[완성 기준]
이렇게 되면 끝이다. (예: 레이드 목록에 새 보스가 보이고, 골라서 한 판 싸울 수 있다)

[참고]
카드 원문 · 노션 페이지 · 스크린샷 · 오류 화면 · "○○처럼"

[크기]
작게 (딱 이것만) / 크게 (빠진 경우 · 따라오는 것까지 알아서)

[바뀌면 안 되는 것]
(없으면 비운다)

[지금 다른 곳에서 하는 작업]
(동시에 맡길 때만. 클로드 코드에 "지금 고치는 파일 목록만 짧게 알려 줘"라고 물어 나온 답을 붙인다)

시작 전에 쉬운 말로 계획을 먼저 보여 주고 내 확인을 받은 뒤 시작해.
끝나면 확인한 증거(점검 결과 · 화면)를 보여 줘.
```

## 아직 뭘 원하는지 흐릴 때

양식 대신 이렇게만 쓴다. Claude가 고를 수 있는 질문을 하나씩 던지고, 답이 모이면 양식을 대신 채운다.

```
○○를 하고 싶은데 아직 정리가 안 됐어. 질문을 하나씩 해서 정리해 주고, 다 모이면 작업 요청서로 써 줘. 아직 코드는 고치지 마.
```

## 클로드 코드에서 지킬 버릇

- **일 하나에 대화 하나.** 다른 일로 넘어갈 때는 `/clear`로 새로 시작한다. 앞 일의 대화가 남아 있으면 헷갈리고 느려진다.
- **처음 1분은 지켜본다.** 엉뚱한 쪽으로 가면 바로 `Esc`로 멈추고 바로잡는다. 멈춰도 그때까지 한 것은 남는다.
- **두 번 고쳐 말해도 안 되면** 세 번째로 고쳐 말하지 말고 `/clear` 하고, 배운 것을 넣어 요청을 새로 쓴다.
- **되돌리기:** `/rewind`(또는 빈 입력창에서 `Esc` 두 번)로 코드와 대화를 앞 시점으로 돌린다. 겁내지 말고 해 본다.
- **"다 됐다"는 말만 믿지 않는다.** 점검 결과나 화면을 보여 달라고 한다. 혼자 돌려 둔 작업이라면 그것이 유일한 증거다.

## 채워 쓴 예

```
[하고 싶은 것]
레이드에 새 보스 「잿빛 군주」를 넣고 싶다.

[완성 기준]
레이드 목록에 잿빛 군주가 보이고, 5단계 난이도 모두 골라서 싸울 수 있다.

[참고]
노션 「맥스」의 잿빛 군주 카드. 싸우는 느낌은 기존 보스 ○○ 비슷하게.

[크기]
작게

[바뀌면 안 되는 것]
기존 보스들

[지금 다른 곳에서 하는 작업]
game/v1.8.5.js, index.html

시작 전에 쉬운 말로 계획을 먼저 보여 주고 내 확인을 받은 뒤 시작해.
끝나면 확인한 증거(점검 결과 · 화면)를 보여 줘.
```
